# Azkar Tracker

Azkar Tracker is a simple and modern React application to help users read and keep track of their **Morning, Evening, and Sleep Azkar** (Islamic supplications). The app uses **React**, **Tailwind CSS**, and **Material-UI** for styling and components.  

You can check the live version here: [Azkar Tracker](https://azkar-tracker.vercel.app/)

---

## Features

- Track your **Morning, Evening, and Sleep Azkar** with counters.
- Reset counters anytime.
- Shows a **completion message** when all Azkar are done.
- Responsive design with **Tailwind CSS**.
- Interactive buttons and icons powered by **Material-UI**.
- Persistent counters using **localStorage**.

---

## Pages

1. **Home Page**  
   - Navigate to Morning, Evening, or Sleep Azkar.
   - Beautiful dashboard with icons and description for each type.

2. **Azkar Detail Page**  
   - Displays a list of Azkar for the selected type.
   - Click each item to decrement its counter.
   - Reset button to restore counters.
   - Snackbar notification when all Azkar are completed.

---

## Tech Stack

- React (React Router for navigation)
- Tailwind CSS
- Material-UI (Icons, Snackbar, Buttons)
- LocalStorage for persistence
